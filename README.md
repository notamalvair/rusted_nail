# rusted_nail

Торговый бот для pump.fun на Rust поверх [pumpapi.io](https://pumpapi.io): стрим событий + Trade API.

## Структура

| Крейт | Что делает | I/O |
|---|---|---|
| `nail-core` | события, намерения, позиции, портфель | нет |
| `nail-strategy` | `sniper`, `momentum`, `copytrade`, правила выхода | нет |
| `nail-risk` | лимиты позиции/экспозиции, дневной стоп, kill switch | нет |
| `nail-engine` | события → стратегии → риск → намерения; учёт ордеров в полёте | нет |
| `nail-sim` | paper-исполнение с комиссией и проскальзыванием | нет |
| `nail-feed` | WebSocket-стрим с переподключением, разбор JSON | сеть |
| `nail-exec` | клиент Trade API (lightning) | сеть |
| `nail-bot` | бинарник `rusted_nail`, конфиг | сеть |

Логика решений не знает про сеть, поэтому один и тот же код пойдёт в paper, бэктест и боевой режим.

## Запуск

```sh
cp config.example.toml config.toml
cargo test
cargo run --release              # paper: живой стрим, виртуальные сделки
```

Боевой режим — только осознанно:

```sh
cp .env.example .env             # отдельный кошелёк с небольшим балансом
set -a; source .env; set +a
cargo run --release -- --live
```

## Статус

- Параметры стратегий и комиссия в `[sim]` — заглушки до анализа исторических данных.
- Paper-исполнение мгновенное, без задержки и влияния на цену; честная модель будет в бэктесте.
- В `--live` исполнение подтверждается собственной сделкой из стрима; суммы пока без учёта комиссий.
- Дальше: крейт `backtest` по паркетам, подбор параметров, замер задержек, Jito/`maxSlot`.

`.env` и `config.toml` в `.gitignore`. Ключи в репозиторий не коммитить.
