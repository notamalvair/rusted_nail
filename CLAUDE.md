# rusted_nail — контекст для Claude

Торговый бот для pump.fun на Rust поверх pumpapi.io (стрим `wss://stream.pumpapi.io/`, Trade API
`POST https://api.pumpapi.io`). Доки API: https://pumpapi.io/llms-full.txt. Общение с владельцем — по-русски.

## Устройство
Cargo workspace, см. таблицу в README. Главное правило: `core`, `strategy`, `risk`, `engine`, `sim`
не имеют зависимостей и I/O; сеть только в `feed`, `exec`, `bot`. Один и тот же `Engine` работает
в paper, replay и live.

- Бинарники: `rusted_nail` (paper по умолчанию, `--live` для реальных денег), `replay` (архивы стрима).
- Панель управления: http://127.0.0.1:8787, только loopback.

## Правила
- `unsafe`, `unwrap`, `expect`, `panic!`, `todo!` запрещены линтами; CI: fmt, clippy `-D warnings`, тесты.
- Ключи только из переменных окружения; `.env` и `config.toml` в `.gitignore`.
- Live-режим включается только флагом `--live`, никогда из UI или конфига.
- Не добавлять бандлеры, volume-ботов, сэндвичи и прочую манипуляцию рынком.
- Числа в `config.example.toml` — заглушки, пока не подобраны по данным.

## Состояние на 2026-11-16
Сделано: три стратегии (sniper, momentum, copytrade), выходы (TP/SL/trailing/timeout/dev sold),
риск-лимиты, paper с задержкой исполнения, replay со статистикой гонки снайперов, веб-панель.

Не проверено на реальных данных: формат полей стрима в `feed` (взят из доков), страница панели
в браузере, replay на настоящих архивах, live-исполнение.

## Данные
Выводы из каталога квинтилей владельца: `docs/data-findings.md`. Главное: комиссия пула берётся
из событий (на кривой обычно 1.25%), mcap между токенами не сравнивать (supply 1 или 2 млрд),
торгуем только SOL-пулы. В облачной среде нет DuckDB/pyarrow: для чтения Parquet есть
`tools/pqlite.py` (системный libzstd через ctypes).

Наборы владельца лежат в `datasets/` (QUINTILES, TOKEN_FEATURES_V1); сплит по датам:
train 02.11, validation 09.11, test 16.11 — test не трогать при подборе. Исходы
`TOKEN_FEATURES_V1` с багом endpoint, считаем по as-of ценам: `research/asof.py`.
Главный вывод: почти всё преимущество в первые 5 с после создания; momentum на 15–30 с не
подтвердился. Репозиторий публичный: личный контекст владельца (`PROJECT_CONTEXT.md`) не коммитить.
